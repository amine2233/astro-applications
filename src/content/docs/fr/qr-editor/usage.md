## Créer votre premier QR code

1. Ouvrez **QR Editor** et appuyez sur **Nouveau**.
2. Choisissez ce que le code doit contenir — un lien, du texte, des identifiants Wi-Fi ou une carte de contact.
3. Appuyez sur **Générer** pour créer le code de base.

## Personnaliser le design

### Couleurs & formes

Choisissez une couleur de premier plan et d'arrière-plan, ainsi qu'un style de points et de coins dans le sélecteur de formes.

:::tip
Conservez un contraste suffisant entre le premier plan et l'arrière-plan — un code magnifique mais illisible ne sert à rien. QR Editor vous avertit si le contraste devient trop faible.
:::

### Ajouter un logo

Appuyez sur **Logo**, choisissez une image dans votre photothèque, et positionnez-la au centre. QR Editor augmente automatiquement la correction d'erreur pour que le code reste lisible.

## Exporter

Appuyez sur **Exporter** et choisissez un format et une taille adaptés à l'usage prévu — impression ou numérique.

## Abonnement Pro

Certaines options de personnalisation avancées et certains formats d'export font partie de l'abonnement **Pro**. Consultez les [conditions d'utilisation](./eula/) pour le détail de l'abonnement, ou **Réglages › Restaurer les achats** si vous êtes déjà abonné.
